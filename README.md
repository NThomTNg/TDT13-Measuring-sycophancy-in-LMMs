# Do factual and moral sycophancy rank LLMs the same way?

Data and code for the TDT13 project report (NTNU, autumn 2026) by Nhan Thomas Trong Nguyen.

No new model outputs were generated. All numbers are taken from published papers.

| File | Contents |
|---|---|
| `extracted_values.csv` | Every value used in the report, with the study, the model name as written in the study, the matched ELEPHANT model and match level (L1 exact, L2 same line, L3 related), the measure, its direction, and where in the paper it was taken from |
| `make_figures.py` | Draws Figure 1 (pipeline) and Figure 2 (scatter plot) with matplotlib |

Values were extracted on 31 October 2026. Two values from Sharma et al. (2024) are only shown in their Fig. 2b and were not extracted.
